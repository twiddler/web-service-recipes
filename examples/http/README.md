This is a minimal working example of how to deploy an HTTP service on a single machine.

# Scope

This includes

- answering HTTP requests with `200` and "Hello world!", and
- opening the port for accepting HTTP requests.

We deliberately do not

- sandbox anything,
- harden anything, or
- do anything else that is not _strictly_ needed.

# Deploying

See `./scripts` for ways of how to deploy this.
